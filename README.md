# ちゃっと雀

**対象ファイル：ChatJan-1.0.5.xdc**

Delta Chatのチャットで開いて遊ぶ、簡易ルールの対戦麻雀アプリです。1人とCPU3人で遊ぶ「CPU対戦」と、友だちと遊ぶ「グループ対戦」があります。

## スマホ縦画面の表示

1.0.5では、幅600px以下の画面で手牌を7枚ずつの2段にし、操作ボタンの上に固定表示します。14枚全てを見るための横スクロールは不要です。鳴いた組は手牌の上、自分の捨て牌は下の小さな欄に表示します。捨て牌が多いときはその欄を縦にスクロールできます。

## まず一人で遊ぶ

1. [ChatJan-1.0.5.xdc](ChatJan-1.0.5.xdc) を端末に取得し、Delta Chat内で開きます。
2. メニューの「CPU対戦」にある「今すぐ開始」を押します。
3. 「あなたの手番」になったら、不要な牌を1枚タップして捨てます。確認画面はありません。
4. 和了できるときは「ツモ」または「ロン」が表示されます。和了する場合は、そのボタンを押します。
5. 和了後は「続ける」、流局後は「再開」で次の局へ進みます。

パソコンでは「タップ」を「クリック」と読み替えてください。

## 操作の早見表

| 操作 | 使い方 |
| --- | --- |
| 打牌 | 自分の手番で手牌を1枚タップします。 |
| ツモ | 自分で引いた牌で和了するときに押します。形と役が必要です。 |
| ロン | 相手の捨て牌で和了するときに押します。役とフリテンも判定されます。 |
| ポン | 相手の捨て牌を使って同じ牌3枚の組を作ります。成立後に1枚捨てます。 |
| チー | 直前の人の捨て牌で連続した3枚の組を作ります。表示された候補の組を選び、成立後に1枚捨てます。 |
| 見送り | 鳴きや和了を見送ります。応答待ちの進行を止めないため、鳴かない場合も押してください。 |
| リーチ | 鳴いていない聴牌の手で宣言し、聴牌を保つ牌を捨てます。1000点と残り山4枚以上が必要です。 |
| 並べ替え | 操作欄の「⇅」を押します。 |
| 音の設定 | 上部の効果音・ボイスを切り替えます。歯車のボタンで音量や声を設定できます。 |
| ヘルプ | 上部の疑問符ボタンを押します。 |

## 友だちと遊ぶ

1. 同じDelta Chatグループへ、この版の `.xdc` を送ります。
2. 全員が**同じ添付**を開き、「グループ対戦」の「ロビーへ」を押します。
3. 2人以上の参加者が表示されたら、ロビー先頭の人が「ホストとして開始」を押します。
4. 人間は2〜4人、不足席はCPUが担当します。5人目以降は打牌に参加できません。
5. 対局中、ホストはアプリを開いたままにしてください。次局の開始もホストが操作します。

操作の反映には10秒以上かかる場合があります。連打せず、相手の応答と通信を待ってください。ホストが閉じた場合や、通信が完全に切れた場合は進行が止まります。ホストの自動交代はありません。

別の添付として送り直したものは別の対戦場所です。全員が同じチャット内の同じ添付を開いてください。

## ツモできないとき

形が揃っていても、役がなければ和了できません。ポンやチーをした手には「門前ツモ」の役が付きません。ドラだけでも和了できません。

この版では、自分のツモ後に形が揃い、役がないと、画面下に**「役なしのため和了できません」**と表示します。このメッセージは、他人の捨て牌を確認している場合や、フリテンの理由を説明する表示ではありません。

自分で待ち牌を捨てている場合や、ロンを見送った直後などは、フリテンでロンできないことがあります。フリテンでも、役と形が揃った自分のツモ和了は可能です。

## この版のルール

- 対応役：立直、門前清自摸和、断么九、役牌、七対子、国士無双、平和、一盃口・二盃口、対々和、混一色・清一色。
- ドラは加算のみ。喰いタンあり。複数ロンは頭ハネです。
- 符は七対子25符、平和ツモ20符・ロン30符、その他40符の簡易計算です。
- その他の役、カン、赤ドラ、裏ドラ、一発、連荘・親の移動、ノーテン罰符、終局順位計算は未対応です。未対応役だけの手では和了できません。

正式な全役・全符計算を実装した競技用アプリではありません。同期データには手牌と山牌を含み、改造クライアントに対する不正防止機能はありません。

## 通信と保存

- CPU対戦は開始後、通信なしで遊べる構成です。日本語の読み上げは端末の音声機能に依存します。
- 通信対戦には、相手に操作を届ける通信が必要です。
- 音の設定は端末に保存されます。
- 通信対戦は受信した更新履歴から復元する仕組みです。CPU対戦には、アプリを閉じた後に同じ局を再開する保存機能はありません。
- 版の確認は添付名の **ChatJan-1.0.5.xdc** を基準にしてください。アプリ内には古い版番号が残っている箇所があります。
